測試案件列表數量限制修復

這個測試檔案用來驗證後端 API 的 100 筆限制是否已經修復

測試步驟：

  1. 開啟瀏覽器開發者工具 (F12)
  2. 進入申請案件列表頁面
  3. 查看 Network 標籤中的 API 請求
  4. 確認 grants API 請求是否：
    • URL 中沒有 limit 參數（因為前端設為 undefined）
    • 回傳的資料筆數超過 100 筆（如果資料庫有超過 100 筆資料）
  5. 查看偵錯資訊中的「已載入案件數」是否超過 100

修復內容：

  • ✅ 後端 API 路由層：預設 limit 從 100 改為 10000
  • ✅ 後端 CRUD 層：預設 limit 從 100 改為 10000
  • ✅ 後端搜尋 API：預設 limit 從 100 改為 10000
  • ✅ 前端：正確設置 limit: undefined
  • ✅ 重新啟動後端 API 服務

預期結果：現在應該能載入所有符合篩選條件的案件資料，不受 100 筆限制
